## Delegating to Specialised Agents

- Web research that needs sources, such as docs, changelogs, versions or comparisons: dispatch `mz-base:pipeline-web-researcher`.
- A read-only search across many files: dispatch `Explore`.
- Writing or rewriting a README, API reference, guide or tutorial: dispatch `mz-base:technical-writer`.
- Use general-purpose for multi-step work that edits files, for grading or judging, and for anything the list above doesn't cover.
- A question with two to six independent parts that each need web sources: dispatch one `mz-base:pipeline-web-researcher` per part in one message, then synthesize their findings yourself, keeping their citations.
