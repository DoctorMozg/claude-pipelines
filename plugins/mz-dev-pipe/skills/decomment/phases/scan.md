# Phase 1 — Scan target files

## Inputs

- `state.md` (Phase 0 wrote `scope_mode`)
- `$ARGUMENTS` (optional path/glob override)

## Outputs

- `.mz/task/<task_name>/scope_files.txt` — one absolute path per line (post-scope, pre-extension-filter)
- `.mz/task/<task_name>/candidates.md` — markdown table for proposer dispatch

## Steps

### 1. Resolve scope into file list

Read `state.md` for `scope_mode`. Then dispatch on the mode.

**scope_mode=branch** (default):

1. Bash: `git rev-parse --verify main 2>/dev/null || git rev-parse --verify master 2>/dev/null`. Capture the surviving ref as `<base>`.
1. If neither exists, present AskUserQuestion to the user — which branch is the base? Three options: **main**, **master**, **<other>** (free-form ref). Loop until the supplied ref resolves via `git rev-parse --verify`.
1. Bash: `git symbolic-ref --short HEAD 2>/dev/null` to detect the current branch. If the command returns empty (detached HEAD), present AskUserQuestion asking the user to supply a base ref explicitly. Loop until valid.
1. If the current branch equals `<base>`, present AskUserQuestion: `You are on <base>; there is no branch diff to scan.` Three options: **switch to working-tree scope**, **supply an explicit path**, **abort**. Loop until resolved. Update `state.md` `scope_mode` if the user switches modes.
1. Bash: `git diff "$(git merge-base HEAD <base>)..HEAD" --name-only --diff-filter=AM`. Write raw output to `scope_files.txt` as absolute paths — prepend the repo root from `git rev-parse --show-toplevel` to each entry.
1. A dirty working tree is not an error in branch mode. If `git status --porcelain` returns non-empty, record a `notes:` line in `candidates.md` (do not abort).

**scope_mode=working**:

1. Bash: `git status --porcelain | awk '{print $2}'` — modified, added, and untracked tracked-eligible paths in the working tree.
1. Prepend the repo root and write to `scope_files.txt`.

**scope_mode=global**:

1. Bash: `git ls-files` — every tracked file.
1. Prepend the repo root and write to `scope_files.txt`.
1. Emit a chat warning before continuing: global scope is expensive. Compute `wc -l scope_files.txt` and surface the file count plus a rough Sonnet-cost estimate (60-file branch ≈ ~$3.60; scale linearly) so the user can `Reject` at Phase 3.5 and narrow scope.

**Explicit path override** (any tokens following the `scope:` token):

1. Treat each token as a path or glob.
1. For each token, run `find <path> -type f 2>/dev/null` when the token resolves to a directory, or `git ls-files <pattern>` when it looks like a glob. Concatenate results.
1. Prepend the repo root if the resulting paths are not already absolute. Write to `scope_files.txt`.

### 2. Filter by extension (allowlist)

For each path in `scope_files.txt`, keep only those matching one of these extensions:

`.py .pyi .sh .bash .zsh .ts .tsx .js .jsx .mjs .cjs .rs .cpp .cc .cxx .c .h .hpp .hxx .hh .go .java .kt .swift .cs .rb .php`

Drop everything else. When an explicit path override drops a user-supplied file because its extension is outside the allowlist, surface this in `candidates.md` under a `## Excluded by extension` section — do not silently drop a user's explicit request.

### 3. Filter codegen by glob

Drop any path matching:

- `**/*.pb.{go,ts,py}`
- `**/*_pb2.py`, `**/*_pb2_grpc.py`
- `**/*.gen.{ts,go}`
- `**/*.generated.*`
- `**/openapi/*.{ts,py}`
- `**/dist/**`, `**/build/**`, `**/.next/**`, `**/node_modules/**`, `**/target/**`, `**/vendor/**`, `**/__pycache__/**`

### 4. Filter codegen by content

For each remaining file, Read the first `CODEGEN_CONTENT_SCAN_LINES` (=50) lines. If any line contains `Generated by`, `DO NOT EDIT`, `auto-generated`, or `@generated` (case-insensitive substring match), drop the file.

### 5. Size warning

For each remaining file, count LOC (Bash: `wc -l <path>`). If LOC > `MAX_FILE_LOC` (=4000), tag the row in `candidates.md` with `oversize` and keep it in the dispatch list. The proposer chunks oversize files internally; the orchestrator does not drop them.

### 6. Write candidates.md

Format:

```markdown
# Decomment candidates

| # | path | language | size_loc | tag | rationale |
|---|------|----------|----------|-----|-----------|
| 1 | <abs path> | python | 320 | normal | branch-modified |
| 2 | <abs path> | rust | 4200 | oversize | branch-modified; >MAX_FILE_LOC |
```

Column rules:

- `path` — absolute path.
- `language` — derived from extension (e.g., `.py` → `python`, `.ts` → `typescript`, `.rs` → `rust`).
- `size_loc` — line count from step 5.
- `tag` — `normal` or `oversize`.
- `rationale` — the scope reason: `branch-modified`, `working-tree`, `global`, or `explicit path`.

Append a summary line:

```
Summary: <N> candidates after filtering (<N> normal, <N> oversize)
```

If any files were excluded by the extension allowlist after an explicit path override, append an `## Excluded by extension` section listing each excluded path with its extension and the rationale `not in allowlist`.

### 7. Update state.md

Update `state.md`:

- `Phase: 1_complete`
- `scope_files: <count>` (rows in candidates.md, not raw scope_files.txt)
- `FilesWritten: [scope_files.txt, candidates.md]`

If `candidates.md` has zero candidate rows (every path was filtered out), emit this chat message: `0 code candidates after filtering. Nothing to do.` Set `state.md` → `Status: complete`, `Phase: aborted_empty_scope`, and exit. Do not dispatch any proposer.

## Red Flags

- You wrote `scope_files.txt` with relative paths instead of absolute — Phase 2 dispatch prompts require absolute paths.
- You forgot to filter `target/`, `node_modules/`, `dist/`, `__pycache__/` — proposers got dispatched on minified or compiled output.
- You silently dropped a file the user passed via explicit path override because it failed the extension allowlist — surface this in `candidates.md` under `## Excluded by extension` instead.
- You treated a dirty working tree as an error in branch-scope mode — branch scope is HEAD-vs-base, not workspace-vs-base.
- You let `scope_mode=global` proceed with 5000+ files without warning the user about cost in chat.
- You used `git diff --name-only` without `--diff-filter=AM`; deletions slip in and the proposer fails on missing files.

## Verification

- `wc -l scope_files.txt` matches the `scope_files` count written to `state.md` (or the post-filter row count if the field tracks survivors).
- The candidates.md table row count matches the file set Phase 2 dispatch will iterate over.
- Grep `candidates.md` for `node_modules`, `dist`, `target`, `__pycache__`, `.next`, `vendor` — zero matches expected.
- Every `path` column entry is absolute (starts with `/`).
- `state.md` `Phase` field is `1_complete` or `aborted_empty_scope` before Phase 2 begins.
